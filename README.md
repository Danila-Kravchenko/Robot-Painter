# Робот-художник

![общий план](<img/Общий план.jpg>)

Робот выполнен в соответствии с **единым техническим заданием** ([ЕТЗ]("https://robot.mipt.ru/uchastnikam/reglament/etz_info/")) Всероссийской олимпиады школьников по информатике в профиле робототехника. Основые критерии ЕТЗ:
* **Задача робота** - нанесение изображений в плоскостей осей Х и У
* **Рабочая область** - лист А4, закрепленный на полигоне. Начало координат - пересечение черных линий, расположенных в левом и верхнем краях листа
* **Размеры** - 300х300х300 мм
* **Скорость** - 100 мм/с
* **Автономность** - полное отсутствие подключения внешних проводных и беспроводных компонентов
* **Погрешность позиционирования** - не более 3 мм
* **Рабочий инструмент** - маркер диаметром 8-18 мм и длиной 120-180 мм
* **Самостоятельная разработка** - запрещается использование готовые специализированных решений для 3Д-принтеров, ЧПУ-станков и т.п.
* **Интерфейс** - возможность выбирать 1 из 10 заданий, предложенных организаторами, а также наличие светодиодов индикации: зеленого и красного
* **Плата коммутации с штырьевыми разъемами:** - наличие макетной платы не менее 400 точек для подключения внешних устройств, а также разъемов с питанием 5В, интерфейсом UART, цифровыми и аналоговым входами

## Алгоритмы и логика управления

В проекте реализована гибридная система траекторного управления, оптимизированная для работы с шаговыми двигателями (ШД) в координатах XY. Алгоритм разделен на два ключевых режима: линейное перемещение и криволинейное позиционирование.

### 1. Линейное перемещение

Режим предназначен для точной прорисовки прямых линий с контролируемой динамикой движения.

*   **Получение скоростей:**
    *   Результирующий вектор желаемой скорости $\vec{V}$ раскладывается на проекции по осям координат ($V_x$ и $V_y$).
    *   Для сохранения геометрии отрезка составляется жесткая пропорция скоростей на основе соотношения приращений координат:
        $$\frac{V_x}{V_y} = \frac{\Delta X}{\Delta Y}$$
    *   Расчет абсолютных значений базовых скоростей выполняется через тригонометрический базис и теорему Пифагора:
        $$V = \sqrt{V_x^2 + V_y^2}$$
*   **Защита от пропуска шагов ШД:**
    *   Интегрирован алгоритм плавного разгона и замедления (рампа скорости) с заданным предельным ускорением $a$.
    *   Во избежание перекоса осей и динамических ударов, мгновенное ускорение по каждой из осей ($a_x, a_y$) рассчитывается строго пропорционально текущей целевой скорости этой оси.
*   **Профиль скорости (Регулятор):**
    *   Реализован пропорциональный регулятор (**П-регулятор**) обратной связи по расстоянию до конечной точки.
    *   Введено ограничение управляющего воздействия (насыщение) на уровне максимальной технологической скорости ($V_{max}$).
    *   **Динамика движения:** График ускорения представляет собой наклонную прямую (линейное нарастание момента), а фаза замедления рассчитывается по экспоненциальному закону для мягкого подхода к целевой точке без перерегулирования.

### 2. Криволинейное перемещение

Режим используется для быстрого позиционирования инструмента по криволинейным траекториям.

*   **Траекторная логика:** Осуществляет перевод рабочего органа из текущей точки в заданную координату по сложной (сглаженной) траектории.
*   **Ограничение динамики:** Перемещение выполняется на фиксированной **минимальной скорости** ($V_{min}$) и **без ускорения** ($a = 0$). Такой подход гарантирует отсутствие вибраций конструкции при резкой смене направления движения инструмента во время холостых переходов.

## Структура ПО
* `etz_main.ino` — главный файл;
* `drivers.ino` — низкоуровневые функции управления роботом (управление моторами, перемещение в точку и т.п.);
* `move.ino` — высокоуровневые функции управления роботом (прорисовка фигур);
* `tasks.ino` — пустые функции для выполнения заданий;
* `interface.ino` — работа интерфейса: выбор задания, отображение информации о задании и т.п.;
* `ports.ino` — функции для обработки разъемов
* `hello_kitty.ino` — массив для отображения изображения

### Порядок запуска
1. **Инициализация:** включите робота и установите маркер в прижимной механизм на расстоянии 2-3 мм от поверхности. Нажмите кнопку на поворотном энкодере для продолжения
2. **Калибровка:** плоттер начнет определение абсолютного нуля по оси у, затем определит положение кончика маркера и сохранит знаение. После отображения интерфейса на дисплее калибровка считается законченной
3. **Определение начала координат:** единократно и автоматически запускается при выборе задачи. Для калибровки датчика света установите робота таким образом, чтобы маркер находился ровно на правой границе черной вертикальной линии. Запустите задачу `calibr` (в самом низу списка): робот откалибрует датчик освещенности и сразу определит начало координат (в дальнейшем проверок не будет)
3. **Старт:** установите указатель на дисплее на нужную задачу и нажмите на ручку поворотного энкодера
